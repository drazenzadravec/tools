# Web Model Context Protocol

WebMCP lets developers expose web application functionality as "tools"—JavaScript functions with natural language descriptions and structured schemas, designed for AI agent ingestion. These tools can be invoked by AI agents, including those built into the browser, hosted in iframes, or running in extensions to actuate web content that was traditionally designed for human interaction. A declarative API based on HTML 'form' elements is also being explored.

### Support
TypeScript applications of server WebMCP implementations supporting tools.
